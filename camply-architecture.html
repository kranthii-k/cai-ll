High-level design

One request, eight hops, back again.

Camply Backend is a modular TypeScript/Express monolith: routes hand off to controllers, controllers lean on services, and everything settles into Postgres through Prisma — with Redis, Socket.IO, Cloudinary and Razorpay wired in at the edges.       Interview script

      Two lengths of the same story — pick one based on how much time the interviewer gives you.

      Camply Backend is a TypeScript Express monolith organized by modules: auth, users, posts, matching, teams, chats, placements, jobs, payments, and notifications. At startup, server.ts:9-25 connects Redis first, then initializes Express and Socket.IO.

      The core stack is Prisma + PostgreSQL for relational data, Redis for caching, rate-limiting and sessions, JWT for auth, Passport for Google OAuth, Cloudinary for media, and Razorpay for subscriptions.

      Request flow is route → auth/validation middleware → controller → services/utilities → Prisma → a standardized API response. Validation is done with Zod. Access tokens are short-lived; refresh tokens are stored in the database and sent via an httpOnly cookie with rotation support.

      Feed responses are cached in Redis, with per-user vote state overlaid dynamically so the cached payload stays reusable across viewers.

      Real-time runs on Socket.IO with JWT handshake auth. Users join a personal room and, where relevant, a chat room — powering live chat, typing indicators and event notifications.

      Payments are subscription-based through Razorpay. Webhooks are verified with an HMAC signature over the raw request body, then subscription state syncs into both the Subscription and User tables.

      Authorization layers normal auth middleware with a Pro-gate that checks cached subscription state and lazily expires outdated Pro users.

      Errors are centralized, with Prisma-specific mappings, and every response uses the same success/error envelope. Architecturally, it's a clean modular monolith with clear boundaries, middleware-driven cross-cutting concerns, real-time support, and production-ready integrations.

      Camply Backend is a modular TypeScript Express monolith — auth, posts, matching, teams, chat, placements, payments, notifications — backed by Postgres via Prisma, with Redis handling caching, rate-limiting and sessions.

      Requests flow through security middleware, JWT auth and Zod validation, into controllers and services, then out through a standardized response envelope. Real-time features run on Socket.IO with per-user and per-chat rooms.

      Subscriptions are Razorpay-based, with signed webhooks syncing Pro status. And it's built with production concerns in mind — centralized error handling, rate limiting, httpOnly refresh cookies, and a CI-gated deploy to Azure.
